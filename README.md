# MINISTRE AI — Sovereign Executive Interface

Implémentation des interfaces **MINISTRE AI uniquement**, à partir des maquettes Stitch fournies :

- Briefing stratégique exécutif
- Espace documentaire intelligent
- Centre de commandement décision → action

## Architecture

Application statique monopage, sans dépendance runtime ni framework. Elle peut être servie directement par GitHub Pages, Vercel, Netlify ou tout serveur HTTP statique.

## Démarrage local

```bash
python -m http.server 8080
```

Puis ouvrir `http://localhost:8080`.

## Navigation

- `#briefing`
- `#dossiers`
- `#decisions`

Les données visibles sont des **données de démonstration**.
